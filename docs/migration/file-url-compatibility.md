# 文件 URL 兼容性

- 历史数据库中的文件 URL 不改写，Node 只负责继续返回和读取现有 URL；
- 新文件统一使用腾讯云 COS，保留 multipart 字段名 `file` 和返回 URL 语义；
- 私有对象通过短期签名 URL 访问，不把 COS 密钥返回前端；
- 测试已覆盖带唯一前缀对象的上传、HEAD、签名下载 URL、删除和删除后不存在；对象已清理；
- AI 证件照生成结果无论来自 base64 还是远程 URL，先写 COS 再写记录，失败时回滚记录；
- 数据库中的历史图片和简历预览 URL 不执行批量迁移；
- 真实 DOCX/PDF 样本需要预发布脱敏文件，TXT/MD/JSON/HTML 解析及不支持格式拒绝已完成 Node 回归。
