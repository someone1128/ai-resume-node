# 隐私和日志数据盘点

## 敏感数据

- 简历模块正文可能包含姓名、电话、邮箱、教育和工作经历；
- `client_user` 包含微信标识、昵称和会员字段；
- 支付表包含订单号、金额、用户关系和兑换码关系；
- COS 对象可能是头像、预览图、证件照或上传简历。

## Node 处理规则

- 请求日志只记录 requestId、方法、路由、状态和用户/管理员内部 ID；
- 不记录 Token、密钥、支付签名、完整简历正文和 AI 完整输入；
- AI 输入长度、超时和错误重试受环境变量限制；
- 测试输出只记录响应形状、计数和脱敏状态；
- 测试账号和测试对象使用登记前缀，不能与真实订单或真实私有文件混用；
- COS 私有文件不通过公开 URL 越权访问；
- 生产环境拒绝 `TEST_AUTH_ENABLED`。

密钥从 Java YAML 中移除并改为环境变量后，旧密钥仍可能存在于 Git 历史；正式上线前应在外部系统轮换曾经暴露过的数据库、Redis、AI 和支付凭据。
