# 后台页面盘点

Snowy 后台包含大量通用页面。本次迁移按实际使用范围保留管理员首页和字典管理；数据库中的每个现有管理员都直接拥有这两个保留模块的完整权限，不再复制 Snowy 的角色、资源和细分权限树。

## 保留页面

| 页面 | Node 接口 | 状态 |
|---|---|---|
| 首页 | `/dev/config/sysBaseList`、`/auth/b/getLoginUser`、`/sys/userCenter/loginMenu` | Node 提供安全启动配置、精简菜单和管理员会话入口；前端启动页已浏览器回归 |
| 字典管理 | `/biz/dict/*`、`/dev/dict/*` | 分页、列表、树、详情、增删改、父项删除保护已在线测试 |

## 延后或废弃页面

Snowy 默认的组织、岗位、角色、资源、日志、监控、邮件、短信、代码生成、示例和系统配置页面不属于当前实际业务范围。它们不再作为 Node 迁移门禁，也不应通过精简 Node 菜单暴露。

管理员真实密码登录需要现有 SM2 私钥或预发布专用凭据；当前默认关闭 `ADMIN_LOGIN_ENABLED`，测试菜单使用受限测试 Token，不允许在 production 开启测试 Token。
