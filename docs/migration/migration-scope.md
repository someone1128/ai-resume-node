# 迁移范围与下线范围

## 必须由 Node 接管

用户端简历、AI 简历、AI 证件照、AI 聊天、会员/兑换码、微信登录边界、微信支付回调边界、COS、校园市场圈、通知、分销/邀请、广告、反馈、字典管理和会员支付 WebSocket。

## 兼容但不复制实现

Snowy Token、旧 API 路径、`code/data/msg/success` 响应外层、Java `CommonPage` 字段、历史文件 URL、现有 MySQL 表和现有管理员账号。

## 不纳入 Node 业务范围

Snowy 的通用组织、岗位、角色、资源、日志、监控、邮件、短信、代码生成和示例页面；不使用的第三方登录、对象存储和配置中心能力；没有静态或日志证据的定时任务。

## 生产切换前仍需外部门禁

真实微信 OAuth 回调、真实支付验签/证书、豆包图片生成、脱敏 DOCX/PDF 样本、备份恢复和灰度回滚。它们不是 Node 代码缺失，而是必须在预发布凭据和隔离环境中执行的验证。
